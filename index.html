Client Portal
⚡ This gives clients a separate, read-only page (portal.html) where they can log in and see only their own requests, status, hours and payment info. It never lets them edit anything. Host portal.html anywhere (a separate URL from this file) and share the login you create below with your client.
Connection Required once, stored only in this browser — never sent anywhere except your own Supabase project
⚠️ Supabase now has two kinds of full-access key: the old legacy service_role key (a long JWT starting with eyJ...) and the new secret key (starts with sb_secret_...). Supabase itself blocks the new sb_secret_ key from ever being used in a browser — you'll get a "Forbidden use of secret API key in browser" error. You must use the legacy one here: Supabase Dashboard → Project Settings → API Keys → look for a "Legacy API Keys" section (you may need to click "reveal") → copy service_role.
